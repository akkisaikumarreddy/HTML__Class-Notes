image tag


src attribute

The src attribute defines the path or URL of the image that the browser fetches and displays inside the img tag.
It is a mandatory attribute because, without it, the image cannot be rendered on the web page

alt attribute

The alt attribute provides alternative text for an image if the image cannot be displayed.
It is important for accessibility, as it helps screen readers describe the image to visually impaired users.
It also serves as a fallback in case the image fails to load.

width and height attributes

The width and height attributes specify the dimensions of the image in pixels.
They help control the size of the image displayed on the web page.
If not specified, the image will be displayed at its original size.

I-frame tag

Media tags

There is no single mediatag in HTML; instead, "media tags" refers to a group of elements used to embed multimedia like images, audio, and video directly into a webpage.

Core HTML Media Tags

img tag : Embeds static or animated images.
video tag : Embeds video content directly on the page.
audio tag : Embeds sound files and music streams.
source tag : Defines multiple media alternatives inside video, audio, or picture tags.
track tag : Adds text-based subtitles, captions, or descriptions to audio and video.
iframe tag : Embeds an external web page or hosted media, like a YouTube video.

HTML Space Entitles
