HTML LISTS

An HTML list organizes content into ordered or unordered formats, making information clear and easy to read.
HTML lists organize content using tags like ul, ol & li.
They improve readability by presenting data in a structured format.

Types of HTML Lists

1. Unordered List (ul): Displays items with bullet points. Where the order of items does not matter, using the ul and li tags.
2. Ordered List (ol): Displays items with numbers or letters. Where the order of items matters, using the ol and li tags.
3. Description List (dl): Displays items with terms and descriptions. Where you want to provide a list of terms and their corresponding descriptions, using the dl, dt, and dd tags.

In HTML, unordered lists (ul) are used to display items without any specific order, and by default, they show bullet points.

Different Type Attributes in HTML Ordered List

The type attribute of (ol) tag specifies the order we want to create.
1. type="1": This will list the items with numbers (default)
2. type="A": This will list the items in uppercase letters.
3. type="a": This will list the items in lowercase letters.
4. type="I": This will list the items with uppercase Roman numbers.
5. type="i": This will list the items with lowercase Roman numbers.

Description List (dl)

Description lists in HTML are used to display terms and their corresponding descriptions in a structured format.
Created using (dl), (dt), and (dd) tags.
(dt) defines the term.
(dd) defines its description of the term.
Commonly used for glossaries, definitions, and metadata lists.

Tables in HTML

HTML tables organize data into a two-dimensional grid of rows and columns.
They are built using structural tags like table, tr, th, and td to display structured information like schedules, price lists, or financial data

table Tag:
The wrapper for the entire table
tr Tag:
Defines a table row.
th Tag:
Defines a header cell (bold and centered by default).
td Tag:
Defines a table data cell that holds actual content.

Caption :Caption Tag provides a title or description for the entire table. thead :thead Tag defines the header section of a table, often containing column labels. tbody :tbody Tag represents the main content area of a table, separating it from the header or footer. tfoor :tfoot Tag specifies the footer section of a table, typically holding summaries or totals. col :col Tag defines attributes for table columns that can be applied to multiple columns simultaneously. colgroup :groups together a set of columns in a table to which you can apply formatting or properties collectively.

Rowspan and Colspan in HTML Table

Rowspan and colspan are powerful HTML table attributes that let you merge cells vertically and horizontally. They make complex table structures cleaner, more flexible, and easier to understand.

  • rowspan controls how many rows a cell spans vertically.
  • colspan defines how many columns a cell spans horizontally.
  • Widely used in complex tables, about 80–90% rely on them for better layout and readability.
