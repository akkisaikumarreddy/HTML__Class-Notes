em tag vs i tag

The em tag in HTML is used to define emphasized text, typically displayed in italics.It conveys semantic meaning, indicating that the emphasized text is important.

The i tag in HTML is used to define italicized text.It is typically displayed in italics but does not convey any semantic meaning.

u tag vs ins tag

While both the u and ins tags render text with a default underline in most browsers, they have completely different semantic meanings in

The u tag represents an Unarticulated Annotation (such as highlighting a spelling mistake or a proper name).

The ins tag represents Inserted text, indicating that the content has been added to the document.

The s tag semantic meaning is Text that is no longer accurate or relevant.

The strike tag semantic meaning is Purely visual strikethrough styling.
