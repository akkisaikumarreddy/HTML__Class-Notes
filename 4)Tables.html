Colspan

The colspan attribute in HTML is used to merge table cells horizontally.
It specifies how many columns a single cell should span or stretch across within an HTML table.

By using { colspan=" " } inside where you want to use like <th>,<td>tags. and in that space you have to give number how many columns you are merging. Here i'm merging 2 columns so { colspan="2" }

Rowspan

The rowspan attribute in HTML merges table cells vertically, allowing a single cell to span across multiple rows. It can be applied to both table data <td> and table header <th> elements.

By using { rowspan=" " } in that space you have to give number how many rows you are merging. Here i'm merging 4 rows so { rowspan="4" }
