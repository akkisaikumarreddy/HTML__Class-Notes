Forms

<Form> tag is used to create an HTML form that collects user input and sends it to a server for processing.
It acts as a container for interactive controls like text fields, checkboxes, and submission buttons.

  • Acts as a container for input elements like text fields, checkboxes, and buttons.
  • Enables data submission using GET/POST and supports attributes like action, method, and enctype.

Here is the Basic Form

  • <from> : Defines a form where users can enter data.
  • action="/submit" :Tells the browser where to send the form data after submission. Here, it will send to /submit (a server endpoint).
  • method="POST" :Specifies how data is sent. POST means the data goes in the request body (commonly used for secure submissions like login, registration).
  • <label for="firstname"> :Associates the text "First Name" with the input field whose id="firstname". Clicking the label focuses the input box.
  • <input>Attributes :
    • id="firstname" :Unique identifier for the field.
    • name="firstname" :The key used when sending data to the server (e.g., firstname=John).
    • placeholder="Enter your first name" :Shows hint text inside the box until the user types.
    • required :Makes the field mandatory.
    • type="text" :Defines it as a single-line text input.
  • type="submit" :Triggers the form submission.
  • value="Submit" :Text displayed on the button.
  • Why / in your code :
    • It’s just a stylistic choice or compatibility measure. Some developers prefer < input / >
    • It looks cleaner and makes it obvious the tag is self-contained.
    • It works in both HTML and XHTML parsers.

Form with fieldset tag and legend tag

  • <fieldset> tag:The <fieldset> tag in HTML is used to group logically related elements within a web form. By default, browsers render a line box (border) around the grouped items to create a clear visual distinction.
  • <legend>A <fieldset> is almost always paired with a <legend> tag, which acts as a caption or heading embedded directly into the border of the box

Form with datalist tag

The <datalist> tag in HTML offers predefined options for an <input> field to assist user input.

  • Users can select a value from the suggested list or enter a custom value.
  • Enhances form usability by providing autocomplete suggestions.

Form with File select box

The file input allows users to select a file from their local device and upload it. It is created using the <input> element with type="file".

Form with Reset and Submit Buttons

Submit and reset buttons are essential in HTML forms. The submit button sends the form data to the server, while the reset button restores the form fields to their default values.

From with target attribute

The target attribute controls where the results of the form submission will open. By default, it opens in the same window (_self).
If you want the result to open in a new tab, set the target attribute to _blank.
