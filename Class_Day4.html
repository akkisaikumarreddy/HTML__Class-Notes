HTML Forms

HTML forms, defined using the form tag, are essential for collecting user input on web pages.
They include interactive controls like text fields, emails, passwords, checkboxes, radios, and buttons.

Basic HTML Form







Form outside, Fieldset inside {Correct Way}

The fieldset is used only for grouping related inputs visually and semantically.
When you submit the form, all inputs inside the fieldset are included in the form submission.

Personal Info

fieldset outside, form inside {unusual}

  • The Fieldset doesn’t actually control form submission — it only groups elements visually.
  • If you put multiple Form tags inside one Fieldset, each form submits separately.
  • This structure is valid HTML but not practical, because fieldsets are meant to group inputs within a single form, not wrap multiple forms.
