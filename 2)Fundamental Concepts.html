HTML Structure

HTML is a markup language used to structure and organize content on webpage,It helps the browser understand the content and show it the right way.

  • Uses elements (tags) enclosed in angle brackets.
  • Tags usually come in pairs, i.e., (opening and closing tags).
  • Defines structure for text, images, links, videos, etc.
  • It helps the browser show the content clearly so people can read it easily.

When we use " shift + ! " and "enter" you will get a basic HTML Structure. In That the main elements or Tags are :

  • !DOCTYPE html : The !DOCTYPE html declaration is used to specify the version of HTML. In this case, it indicates that the document is written in HTML5, which is the latest version of HTML.
  • html : The html element is the root element of the HTML document. Everything inside this element is considered part of the HTML document.
  • head : The head section contains metadata about the document that isn't displayed on the webpage.
  • body : The body tag contains the actual content of the webpage that will be visible to users, such as text, images, and links.



HTML Elements

HTML elements are the basic building blocks of a webpage, defining its structure and content using start tags, content, and end tags.

  • HTML elements start with an opening tag and end with a closing tag , and can contain text, attributes, or other nested elements.
  • Some elements are self-closing (e.g., br, hr, img), and browsers use elements to render the page visually.
  • HTML tags are not case-sensitive. For example, 'B' and 'b' both represent bold text.
  • However, it’s a best practice to use lowercase tags for consistency and readability.

Necessary to Add an End Tag: It Always include closing tags for non-void HTML elements, as missing tags can cause unexpected browser layout issues.

  • Browsers may auto-add missing closing tags.
  • This can lead to unexpected layout issues.
  • Always include closing tags for non-void HTML elements(element that must have both an opening tag and a closing tag).

HTML Empty Element: HTML Elements without any content i.e., that do not print anything are called Empty elements. Empty HTML elements do not have an ending tag.



HTML Attributes

HTML Attributes are special words used within the opening tag of an HTML element. They provide additional information about HTML elements.
HTML attributes are used to configure and adjust the element's behaviour, appearance, or functionality in a variety of ways.

  • Each attribute has a name and a value, formatted as name="value".
  • Attributes give extra instructions to the browser about how an element should look or act.

  • Tag :img
  • Attribute> :src
  • Purpose :The tag is used for embedding images in an HTML page. The src attribute within the img tag specifies the path to the image file you wish to display. This attribute is crucial as it directs the browser to the image’s location on the internet or a local directory.

Types of HTML Attributes

Common HTML Attributes:

  • alt Attribute :"The alt attribute gives a text description of an image so people and browsers know what it shows if the image can’t be seen.
  • width and height Attribute :The width and height Attribute is used to adjust the width and height of an image(in pixels).
  • id Attribute :The id attribute in HTML assigns a unique identifier to an element, allowing it to be targeted by CSS and JavaScript for styling and manipulation purposes.
  • title Attribute :The title attribute adds extra information about an element, usually shown as a tooltip when you hover over it.
  • href Attribute :The href attribute in HTML, used with the a tag, specifies a link destination. Clicking the linked text navigates to this address. Adding `target="_blank"` opens it in a new tab.
  • style Attribute :The style attribute is used to provide various CSS effects to the HTML elements such as increasing font-size, changing font-family, coloring, etc
  • lang attribute :The language is declared with the lang attribute. Declaring a language can be important for accessibility applications and search engines.
